# Our-Little-Chat Frontend
https://ourlittlechat.tech/

This is the frontend for the "Our Little Chatik" application. It provides an interface for users to interact with the chat system, offering a smooth and intuitive experience.

## Features

- Real-time messaging
- User authentication
- Chat history
- User profile management

## Technologies Used

- React
- Redux (Redux Toolkit)
- SCSS
- WebSocket for real-time communication
